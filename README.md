# Перекупы 1С — контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Проект представляет собой учебную версию сайта интернет-магазина «Перекупы 1С», разработанную с использованием Bootstrap.
Предметная область та же, что в контрольной работе №1 (калькулятор 1С, коробочная версия 1С:Бухгалтерии, курс разработчика 1С),
но это отдельная реализация: интерфейс построен на CSS-фреймворке, а не на собственном CSS.

## Подключение Bootstrap

В проекте Bootstrap подключён локально, без CDN. Файлы фреймворка (compiled-версия) размещены в папке `vendor/bootstrap/`.

Используются:

- `vendor/bootstrap/css/bootstrap.min.css`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js`.

```html
<link rel="stylesheet" href="vendor/bootstrap/css/bootstrap.min.css">
<link rel="stylesheet" href="css/custom.css">
...
<script src="vendor/bootstrap/js/bootstrap.bundle.min.js"></script>
<script src="js/main.js"></script>
```

`custom.css` подключается после Bootstrap, чтобы переопределять его стили.
`bootstrap.bundle.min.js` нужен для интерактивных компонентов: мобильного меню, выпадающего списка,
модального окна, карусели, вкладок, accordion и toast. `js/main.js` подключается после него,
потому что использует объект `bootstrap`.

Файлы скачаны с официального CDN Bootstrap, их контрольные суммы совпадают с опубликованными
на getbootstrap.com для версии 5.3.8.

## Реализованные компоненты Bootstrap

| Компонент | Где используется |
|---|---|
| `navbar`, `dropdown` | меню на всех страницах; список «Товары» ведёт на страницы трёх товаров |
| `card` | карточки товаров, контейнер формы заявки, фото на странице товара, блоки контактов |
| `btn`, `btn-group` | кнопки действий; группа кнопок фильтра в каталоге |
| `badge` | метки товаров «Хит», «Скидка», «Новинка», «Акция» |
| `alert` | предупреждение на страницах товаров о том, что проект учебный |
| `modal` | быстрая заявка по кнопке «Заказать» в каталоге |
| `toast` | всплывающее уведомление об отправке заявки |
| `carousel` | слайдер с акцией и товарами на главной странице |
| `nav-tabs` (tabs) | вкладки «Характеристики», «Частые вопросы», «Доставка и оплата» на странице товара |
| `accordion` | частые вопросы на странице товара |
| `breadcrumb` | хлебные крошки на страницах товаров |
| `table` | характеристики товара (`table-striped`, `table-bordered`, `table-responsive`) |
| `list-group` | контакты и режим работы |
| `form-control`, `form-select`, `input-group`, `form-check` | форма заявки и форма в модальном окне, проверка через `was-validated` и `invalid-feedback` |

## Использование Bootstrap-сетки

| Блок | Классы колонок | Как перестраивается |
|---|---|---|
| Шапка | `col-12` | одна колонка на всю ширину контейнера |
| Hero-блок | `col-12 col-lg-6` | текст над каруселью, на большом экране рядом |
| Преимущества | `col-12 col-md-6 col-lg-3` | по одному, по два, по четыре в строку |
| Товары на главной и в каталоге | `col-12 col-md-6 col-lg-4` | по одному, по два, по три в строку |
| Страница товара | `col-12 col-lg-6` | фото над описанием, на большом экране рядом |
| Форма заявки | `col-12 col-lg-8` и поля `col-12 col-md-6` | поля по одному, с планшета по два в строку |
| Контакты | `col-12 col-lg-6` | карточки друг под другом, на большом экране рядом |
| Подвал | `col-12 col-md-6` | на телефоне друг под другом, с планшета в одну строку |

Hero-блок использует `container-fluid` для фона на всю ширину экрана, а содержимое — `container`.
Промежутки между колонками задаются классами `g-3` и `g-4` у `row`.

## Самостоятельные доработки

Сверх пошаговых инструкций методических указаний:

1. **Локальное подключение Bootstrap** из папки `vendor/bootstrap/` вместо CDN.
2. **Дополнительные страницы:** три отдельные страницы товаров вместо одной `product.html`
   и страница `contacts.html`.
3. **Каталог:**
   - фильтр по категориям «Техника», «Программы», «Обучение» (`btn-group`);
   - сортировка по популярности и цене (`form-select`);
   - счётчик показанных товаров; он объявляется программами экранного доступа через `aria-live`;
   - в карточках каталога указана категория товара, на главной — короткий вариант карточки без неё.
4. **Сценарий заявки:**
   - кнопка «Заказать» открывает модальное окно, где уже указан выбранный товар;
   - «Оформить заявку» на странице товара открывает `order.html` с этим товаром, уже выбранным в списке (`order.html?product=...`);
   - обязательные поля проверяются через Bootstrap-валидацию: подсветка полей и подсказки под ними;
   - после отправки появляется toast с названием заказанного товара.
5. **Дополнительные компоненты:** `carousel`, `nav-tabs`, `toast`, `dropdown`, `btn-group`, `list-group`
   и `breadcrumb` вместе с `accordion` из методических указаний.
6. **Единый визуальный стиль через `custom.css`:**
   - жёлто-тёмная гамма вместо синих цветов Bootstrap по умолчанию;
   - цвета ссылок, вкладок, активного пункта меню, accordion, фокуса полей и чекбоксов заданы
     через CSS-переменные Bootstrap (`--bs-link-color` и другие), без переписывания компонентов;
   - фото товаров не обрезаются (`object-fit: contain`), а у слайдов карусели одинаковая высота.
7. **Адаптивность:** все страницы проверены при ширине 375, 768, 1024 и 1440 px.
   Контент не выходит за край экрана, таблица прокручивается внутри `table-responsive`,
   подвал прижат к низу окна на коротких страницах.
8. **Доступность:** у всех полей есть `label`, у изображений — осмысленный `alt`,
   у карусели и кнопок-иконок — подписи `aria-label` и `visually-hidden`,
   у активных пунктов меню — `aria-current`, у кнопок фильтра — `aria-pressed`.

## Как проверить проект

1. Открыть `index.html`. Проверить карусель: стрелки, индикаторы, клик по слайду с товаром открывает страницу товара.
2. Уменьшить окно до ширины телефона (DevTools → режим устройства) и раскрыть меню кнопкой.
3. В меню открыть выпадающий список «Товары».
4. Открыть `catalog.html`:
   - нажать кнопки фильтра и изменить сортировку;
   - нажать «Заказать», отправить пустую форму и увидеть подсказки;
   - заполнить форму и отправить: окно закроется, появится уведомление.
5. Открыть страницу товара. Переключить вкладки, раскрыть вопросы в accordion.
   Нажать «Оформить заявку»: в форме на `order.html` товар будет уже выбран.
6. Открыть `contacts.html`.
