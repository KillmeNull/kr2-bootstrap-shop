# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Проект представляет собой учебную версию сайта интернет-магазина «Перекупы 1С», разработанную с использованием Bootstrap.
Предметная область та же, что в контрольной работе №1 (калькулятор 1С, коробочная версия 1С:Бухгалтерии, курс разработчика 1С),
но интерфейс построен на CSS-фреймворке, а не на собственном CSS.

## Практическая работа 9

Выполнена главная страница на Bootstrap-сетке.

Реализовано:

- подключение Bootstrap через CDN (CSS и JS Bundle);
- подключение `css/custom.css` после Bootstrap;
- шапка страницы в жёлтых фирменных цветах;
- Bootstrap-навигация с кнопкой раскрытия меню на малых экранах;
- hero-блок на сетке: фон на всю ширину через `container-fluid`, содержимое в `container`;
- блок преимуществ;
- сетка популярных товаров с фотографиями и значками «Хит», «Скидка», «Новинка»;
- подвал страницы, прижатый к низу окна.

## Практическая работа 10

Тема: «Страница на Bootstrap: компоненты».

Выполнено:

- добавлена единая Bootstrap-навигация на все страницы, с выпадающим списком «Товары» (`dropdown`);
- создана страница каталога `catalog.html`;
- созданы страницы товаров `product.html`, `product-2.html`, `product-3.html`;
- создана страница заявки `order.html`;
- использованы компоненты `navbar`, `dropdown`, `card`, `btn`, `badge`, `alert`, `modal`, `breadcrumb`, `table`,
  `form-control`, `form-select`, `input-group`, `form-check`, `accordion`;
- Bootstrap обновлён до версии 5.3.8 на всех страницах;
- добавлен файл `js/main.js`: проверка форм через Bootstrap-валидацию, название товара в модальном окне,
  выбор товара в форме заявки по ссылке со страницы товара;
- в `css/custom.css` добавлены минимальные стили для изображений;
- проект подготовлен к сдаче контрольной работы №2.

## Использованные компоненты Bootstrap

| Компонент | Где используется |
|---|---|
| `navbar`, `dropdown` | меню на всех страницах; список «Товары» ведёт на страницы трёх товаров |
| `card` | карточки товаров на главной и в каталоге, контейнер формы заявки, фото на странице товара |
| `btn` | «Подробнее», «Заказать», «Оформить заявку», кнопки форм; жёлтые `btn-warning` вместо синих `btn-primary` |
| `badge` | метки товаров «Хит», «Скидка», «Новинка» и «Акция» в hero-блоке |
| `alert` | подсказки в каталоге, на странице товара и в форме; сообщение об успешной отправке |
| `modal` | быстрая заявка по кнопке «Заказать» в каталоге |
| `breadcrumb` | хлебные крошки на страницах товаров |
| `table` | характеристики товара (`table-striped`, `table-bordered`, `table-responsive`) |
| `form-control`, `form-select`, `input-group`, `form-check` | форма заявки и форма в модальном окне |
| `accordion` | блок «Частые вопросы» на страницах товаров |

## Использование Bootstrap-сетки

| Блок | Классы колонок | Как перестраивается |
|---|---|---|
| Шапка | `col-12` | одна колонка на всю ширину контейнера |
| Hero-блок | `col-12 col-lg-6` | одна колонка, на большом экране две |
| Преимущества | `col-12 col-md-6 col-lg-3` | по одному, по два, по четыре в строку |
| Товары на главной и в каталоге | `col-12 col-md-6 col-lg-4` | по одному, по два, по три в строку |
| Страница товара | `col-12 col-lg-6` | фото над описанием, на большом экране рядом |
| Форма заявки | `col-12 col-lg-8` и поля `col-12 col-md-6` | поля по одному, с планшета по два в строку |
| Подвал | `col-12 col-md-6` | на телефоне друг под другом, с планшета в одну строку |

Промежутки между колонками задаются классами `g-3` и `g-4` у `row`.

Использованные utility-классы: отступы `my-*`, `mb-*`, `mt-*`, `py-*`, `p-*`;
цвета `bg-warning`, `bg-warning-subtle`, `bg-dark`, `bg-light`, `text-white`, `text-body-secondary`;
выравнивание `d-flex`, `justify-content-between`, `align-items-center`, `text-center`, `text-md-end`, `gap-2`;
оформление `border`, `rounded`, `shadow-sm`, `h-100`.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product.html`, `product-2.html`, `product-3.html` — страницы товаров;
- `order.html` — форма заявки;
- `css/custom.css` — дополнительные стили проекта;
- `js/main.js` — проверка форм и работа модального окна;
- `images/` — изображения проекта;
- `README.md` — описание проекта.

## Как посмотреть проект

Открыть файл `index.html` в браузере. Для работы Bootstrap нужен интернет: фреймворк подключается через CDN.
